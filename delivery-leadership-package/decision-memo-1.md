# Decision Memo: Zip Code Additional Scope Request_

**Date:** September 1, 2026
**Author:** Tina Matthys
**Decision area:** Zip Code Additional Scope Request

## Context

Marketing wants a **ZIP-code field** on the quote form by Thursday. They're planning a regional-pricing A/B test and say the pricing table is ready on their side.

## Options considered

1. **Option A: Update priorities to add zip code requirement by Thursday with no scope change otherwise.** Pro: extra functionality added; Con: Possible missed deadline
2. **Option B: Decline zip code requirement update, but schedule it for after this week's release.** Pro: Original work and deadline are preserved; Con: extra functionality is delayed
3. **Option C: Prioritize zip code requirement and remove all optional work.** Pro: extra functionality added with less risk for missed deadline; Con: Other optional features might be of more value to the customer

## Recommendation

Option B would be the preference for keeping the project aligned and including all prioritized work first.

## Why

The original delivery stays on track and intact. The additional feature can be added as a fast-follow without risking customer functionality.

## What would change my mind

If marketing came back and required the zip code change regardless of impact, we would need to find a way to include it at the expense of another feature.
